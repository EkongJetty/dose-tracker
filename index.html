    Import dataset

    Upload an Excel (.xlsx) or CSV file with patients, exams, or both.

    Use the template so the column names match. Patients go on a sheet called Patients, exams on a sheet called Exams. A CSV file can hold one of them. Patients that already exist are left alone, and exams that are already saved are skipped, so a file can be uploaded again safely.
